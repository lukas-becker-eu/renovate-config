# AGENTS.md

This repository is the **shared Renovate config preset** for the `lukas-becker-eu` GitHub organisation.

## Purpose

- `default.json` — org-wide Renovate preset, extended by all repos via `"extends": ["github>lukas-becker-eu/renovate-config"]`
- `.github/workflows/renovate.yml` — **reusable** GitHub Actions workflow, called by all repos
- This repo monitors itself with Renovate and releases via release-please

## Directory Structure

```
├── default.json                          Renovate preset (extended by all repos)
├── renovate.json                         Self-monitoring config for this repo
├── CHANGELOG.md                          Auto-generated by release-please
├── .github/
│   ├── workflows/
│   │   ├── renovate.yml                  Reusable Renovate workflow (workflow_call)

└── .claude/
    ├── settings.json                     Claude Code project settings + hooks
    └── hooks/                            Pre/post tool-use guards
```

## Reusable Workflow

All repos call `renovate.yml` via:

```yaml
jobs:
  renovate:
    uses: lukas-becker-eu/renovate-config/.github/workflows/renovate.yml@main
    secrets: inherit
    with:
      log-level: ${{ vars.RENOVATE_LOG_LEVEL || 'info' }}
```

The workflow:
1. Deletes stale Renovate branches (no open PR)
2. Generates an org-scoped GitHub App token
3. Logs in to GHCR (for private Docker image updates)
4. Runs Renovate
5. Alerts (warning annotation + step summary) if any `dependencies` PRs are >7 days old

## Secrets & Variables (GitHub)

Required in every calling repo:

| Name | Type | Description |
|---|---|---|
| `RENOVATE_CLIENT_ID` | Secret | GitHub App client ID for Renovate |
| `RENOVATE_APP_PRIVATE_KEY` | Secret | GitHub App private key for Renovate |

Required in **this** repo additionally:

| Name | Type | Description |
|---|---|---|
| `CI_APP_CLIENT_ID` | Secret | GitHub App client ID for release-please |
| `CI_APP_PRIVATE_KEY` | Secret | GitHub App private key for release-please |

Optional in all repos:

| Name | Type | Description |
|---|---|---|
| `RENOVATE_LOG_LEVEL` | Variable | Renovate log verbosity (`info` / `debug`). Default: `info` |

## Versioning & Releases

- release-please manages releases automatically on push to `main`
- Commit types that trigger a release: `feat` (minor), `fix` / `ci` / `chore` / `perf` (patch)
- Tags: `v0.1.0`, `v0.0.2`, … (no component prefix)

## Commit Conventions

Format: `<type>(<scope>): <description>`

| Type | Bump |
|---|---|
| `feat` | minor |
| `fix`, `ci`, `chore`, `perf` | patch |
| `docs`, `refactor` | no release |

## Local Development

No install step required — the preset is pure JSON.

To test a Renovate run locally:
```bash
LOG_LEVEL=debug npx renovate --platform=github --token=<ghp_...> lukas-becker-eu/renovate-config
```
